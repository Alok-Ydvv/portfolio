# Alok Pratap Yadav - Portfolio

Personal portfolio website built from my resume. It is a static site (HTML, CSS, and vanilla JavaScript) with no build step.

**Live site:** https://alok-ydvv.github.io/portfolio/

## Sections

- Hero and About
- Technical Skills
- Projects: RideSync, LiveBoard, DocuMind, ARGUS
- Education
- Training
- Contact

## Run locally

Open `index.html` in a browser, or start a simple local server:

```bash
python -m http.server 5500
```

Then visit http://localhost:5500

## Deploy

The site is hosted on GitHub Pages from the `main` branch, root folder. Any push to `main` updates the live site.

## Files

| File         | Purpose                                   |
| ------------ | ----------------------------------------- |
| `index.html` | Page content and structure                |
| `style.css`  | Styling, dark theme, responsive layout    |
| `script.js`  | Mobile menu, footer year, scroll reveal   |
